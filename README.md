# LocalSend Website

## Setup

Get dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

## Deployment

Generates the static website in the `dist` directory.

```bash
npm run generate
```

## Contributing

### Adding a new language

1. Add new JSON file in `i18n/locales/` directory.
2. Add the new language in `nuxt.config.ts`.
